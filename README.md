# U酱下载与公告

此仓库提供 U酱正式安装包、版本公告和许可证资料。

- [下载最新版](https://github.com/Czenb/UJNB/releases/latest)
- [全部发行版本](https://github.com/Czenb/UJNB/releases)
- [公告](announcements/latest.json)

开发仓库由维护者私有管理。本应用包含 AGPL-3.0 开源衍生代码；每个正式发行版本的对应源码，以该版本 Release 附件中的 `UJNB-版本号-source.zip` 提供，`SOURCE.txt` 标注源码提交。开发仓库设为私有不改变接收者依据许可证享有的权利。

GitHub 自动生成的 Source code 压缩包只包含本发行仓库内容，请下载名称带版本号的对应源码附件。

公开下载当前仍为正式版 1.2.17。账号内测版通过测试渠道分发，其对应源码随内测安装包提供。
